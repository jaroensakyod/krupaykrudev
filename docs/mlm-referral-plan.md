# แผนระบบคอมมิชชั่นแบบ MLM 3 ชั้น (Referral Tiers) + ระบบตัวแทนขายของผู้ขาย

> สถานะ: **อนุมัติแล้ว — รอสร้างหลังพิธีเปิด 20 ก.ย. 2569**
> ตัดสินใจโดยเจ้าของ: อัตรามาตรฐาน 20/10/5% · เริ่มงานหลังพิธีเปิด
> เพิ่มเติม: อนุมัติระบบตัวแทนขายของผู้ขาย (ข้อ 8) — ผู้ขายตั้งค่าคอมตัวแทนเองได้

## 1. สรุปผู้บริหาร

ต่อยอดระบบ referral เดิม (1 ชั้น, 5% ของค่าธรรมเนียม) เป็นระบบคอมมิชชั่นแบบหลายชั้น
สูงสุด 3 ชั้น แบบ "สร้างทีมขาย" — ได้ค่าแนะนำจากการที่ลูกทีม**ซื้อ**และจากการที่ลูกทีม**ขาย**
โดยหักจากค่าธรรมเนียมแพลตฟอร์ม 15% เท่านั้น (ผู้ขายไม่โดนหักเพิ่ม ผู้ซื้อจ่ายเท่าเดิม)

## 2. โครงสร้างทีม

- ใครสมัครสมาชิกผ่านลิงก์แนะนำของใคร = **ลูกทีมระดับ 1 (L1)** ของเจ้าของลิงก์
- ลูกทีม L1 เปิดร้านแล้วเอาลิงก์ของตัวเองไปชวนคนอื่น = คนนั้นเป็น **L2** ของคนแรก
- ต่อยอดได้ถึง **L3** จบที่ 3 ชั้น (ไม่สร้างต้นไม้ลึกไม่จำกัด)
- ผูกสายทีมตอนสมัคร (ref code) — คงหน้าต่าง attribution 90 วันเดิมไว้ได้ แต่สายทีมถาวร
  (แนะนำ: สายทีมถาวรตอนสมัคร, หน้าต่าง 90 วันใช้เฉพาะกับลิงก์ที่คลิกซ้ำภายหลัง)

## 3. อัตราคอมมิชชั่น (หักจากค่าธรรมเนียมแพลตฟอร์ม 15%)

| ชั้น | % ของค่าธรรมเนียม | = % ของยอดขาย | ตัวอย่าง ขาย ฿100 | ตัวอย่าง ขาย ฿29 |
|---|---|---|---|---|
| L1 (ชวนตรง) | 20% | 3% | ฿3.00 | ฿0.87 |
| L2 (ลูกทีมชวน) | 10% | 1.5% | ฿1.50 | ฿0.44 |
| L3 (ชั้นสาม) | 5% | 0.75% | ฿0.75 | ฿0.22 |
| **รวมจ่ายสูงสุด** | **35%** | **5.25%** | | **แพลตฟอร์มเหลือขั้นต่ำ 9.75%** |

## 4. สองทางรับรางวัล (จุดที่ทำให้เป็น MLM สร้างทีมขาย)

1. **ทีมช้อปปิ้ง** — ลูกทีมซื้อสื่อ → เงินโอนเข้าสายบนทุกชั้น (กลไกเดิมที่มีอยู่ ต่อยอดเป็น 3 ชั้น)
2. **ทีมธุรกิจ** — ลูกทีมเปิดร้านแล้วมียอดขายเกิดขึ้น → สายบนได้ % จากค่าธรรมเนียมของยอดขายนั้น
   (ได้ต่อเนื่องตลอดอายุร้านลูกทีม = passive income แบบถูกกฎหมาย)

รางวัลรวมเข้ากระเป๋าเดียวกับรายได้ขายสื่อ (ledger) — ถอนออกพร้อมกันได้

## 5. เส้นแบ่งกฎหมาย (สำคัญ — ปรับปรุงจากการวิจัย 19 ก.ย. 2569)

- หน่วยงานกำกับธุรกิจขายตรง/ตลาดแบบตรงคือ **สคบ. (สำนักงานคณะกรรมการคุ้มครองผู้บริโภค)**
  — ไม่ใช่ กรมพัฒนาธุรกิจการค้า (แก้ไขจากแผนเดิม)
- พ.ร.บ.ขายตรงฯ 2545 ห้ามแผนที่ให้ "รายได้หลัก" มาจากการรับสมัคร/แนะนำคน —
  ระบบของเราจ่ายจากยอดขายสินค้าจริงเท่านั้น ✅
- **การจ่ายคอมหลายชั้นตามสายงาน (L2-L3) อาจเข้าข่าย "ขายตรงแบบแผนงาน"**
  → ต้องจดทะเบียนกับ สคบ. + มีหลักประกันวงเงิน ก่อนเปิดใช้จริง
- **กลยุทธ์การเปิดใช้ (ปรับใหม่):**
  - ระยะแรก: เปิดเฉพาะ **L1 (ค่าแนะนำโดยตรง)** ซึ่งอ่านเป็น affiliate ปกติ ความเสี่ยงต่ำสุด
  - ก่อนเปิด L2-L3: ให้ทนายตรวจ + จดทะเบียนขายตรงแบบแผนงานกับ สคบ.
    (เอกสารส่ง DBD ที่ทำค้างอยู่เป็นเรื่องพาณิชย์อิเล็กทรอนิกส์ — คนละเรื่องกับสคบ.)
- ตัวอย่างอ้างอิง: Shopee Affiliate (ไทย) จ่ายคอม 1 ชั้น 2% และ Lazada มี sub-affiliate
  1.68-2.64% โดยไม่ถูกมองเป็นขายตรงแบบแผนงาน — เพราะเป็นค่าแนะนำจากยอดขายจริงผ่านลิงก์

## 6. ขอบเขตงานที่ต้องสร้าง

1. **Prisma schema** — `User.referredByUser` (self-relation, บันทึกสายทีมถาวรตอนสมัคร)
   + ปรับ `ReferralReward` → เก็บ level (1-3) และเชื่อม ledger
2. **สมัครสมาชิก** — ผูกสายทีมจาก ref code (แทน attribution แบบหมดอายุสำหรับสายหลัก)
3. **ตอนชำระเงินสำเร็จ (fulfillment)** — เดินสายขึ้น 3 ชั้น จ่าย L1/L2/L3 ตามอัตรา
   เข้า ledger (entryType ใหม่ `REFERRAL_BONUS` เพื่อแยกรายงานได้)
4. **หน้า /dashboard/referrals** — สถิติทีม L1/L2/L3, ยอดคอมแต่ละชั้น, ลิงก์สมัคร,
   อัตราโปร่งใส, ตารางลูกทีมที่ทำยอด
5. **กระเป๋าเงิน** — REFERRAL_BONUS นับในยอดพร้อมถอน (ผ่าน FINANCE_HOLD_DAYS เดียวกัน)
6. **แอดมิน** — สถิติทีม/คอมมิชชั่นรวมใน /admin (เช่น จ่ายคอมไปกี่บาท)

## 7. เงื่อนไขเพิ่มเติมที่ควรมี (แนะนำ)

- คอมมิชชั่นเกิดเฉพาะคำสั่งซื้อที่ "ชำระสำเร็จ" และถูกยกเลิกพร้อมคืนเงินอัตโนมัติ (reversal ตามลูกโซ่)
- กันตัวเองชวนตัวเอง (ไม่นับสายซ้ำ)
- ลิมิตป้องกันยิงระบบ: คำนวณจากยอดจริงใน ledger เท่านั้น ไม่มีโบนัสล่วงหน้า

## 8. ระบบตัวแทนขายของผู้ขาย (Seller Agent Program) — อนุมัติแล้ว

**หลักการ:** ผู้ขายสร้าง "ทีมขายของตัวเอง" โดยตั้งค่าค่าคอมตัวแทนเอง — หักจาก
**ส่วนของผู้ขาย (85%)** ไม่กระทบค่าธรรมเนียมแพลตฟอร์ม 15% และไม่กระทบคอม MLM
ของแพลตฟอร์ม (คนละแหล่งเงิน — ซ้อนกันได้)

### ผู้ขายทำได้
- เปิด/ปิดโปรแกรมตัวแทน + ตั้งอัตราค่าคอมเอง (ระบบจำกัด **ไม่เกิน 50% ของส่วนผู้ขาย**
  กันตั้งจนขาดทุน) ต่อร้าน (v1) — ต่อสินค้าทำทีหลังได้
- ลิงก์ "รับสมัครตัวแทน" → อนุมัติ/ปฏิเสธเอง (มีโหมด auto-approve)
- Dashboard: ยอดขายที่ตัวแทนแต่ละคนทำ + คอมที่ต้องจ่าย

### ตัวแทนทำได้
- สมัครเป็นตัวแทนร้านไหนก็ได้ (ใช้บัญชี KruPayKru เดิม)
- ได้ลิงก์ขายของร้าน/สินค้า (ผูก agent id) → แชร์ต่อ → คนซื้อผ่านลิงก์ = ได้คอม
- คอมเข้ากระเป๋าเดียวกับรายได้อื่น ถอนรวมกันได้

### แบ่งเงิน (ตัวอย่าง ขาย ฿59, คอมตัวแทน 10%)
| ผู้รับ | จำนวน |
|---|---|
| ค่าธรรมเนียมแพลตฟอร์ม 15% | ฿8.85 (ไม่กระทบ) |
| ตัวแทน 10% ของราคา | ฿5.90 |
| ผู้ขายเหลือ | ฿44.25 (จาก ฿50.15) |
| ทีมแนะนำแพลตฟอร์ม | ยังได้จาก ฿8.85 ตามระบบ MLM เดิม |

### กติกากันมั่ว
- คอมเกิดจากยอดขายจริงเท่านั้น · คืนเงิน = หักคืนคอมตัวแทนอัตโนมัติ
- ห้ามเป็นตัวแทนร้านตัวเอง · ป้องกันตัวเองซื้อเองผ่านลิงก์ตัวแทน
- อัตราสูงสุดที่ระบบยอม: 50% ของส่วนผู้ขาย (ตั้งเกินระบบ block)

### ขอบเขตงาน (รวมอยู่ในงานหลังพิธีเปิดชุดเดียวกัน)
1. Schema: `SellerAgent` (sellerId, agentUserId, ratePct, status) + `agent` บน attribution ของออเดอร์
2. ลิงก์ตัวแทน + การผูกยอดขายตอน checkout
3. ตอนชำระเงินสำเร็จ: หักคอมตัวแทนจากส่วนผู้ขาย → ledger (entryType `AGENT_COMMISSION`)
4. หน้าผู้ขาย: จัดการตัวแทน/ตั้งอัตรา/ดูยอด · หน้าตัวแทน: ยอดขาย+คอมของตัวเอง
5. คืนเงิน: reversal คอมตัวแทนพร้อมกัน
6. แอดมิน: สถิติโปรแกรมตัวแทนรวม

## 9. ผลวิจัยจากเว็บ (19 ก.ย. 2569) — สิ่งที่เรียนรู้และนำมาปรับ

### 9.1 เทียบมาตรฐานตลาด
| ระบบ | โครงสร้าง | เทียบกับของเรา |
|---|---|---|
| Shopee Affiliate (ไทย) | Direct 2.00% / Indirect 0.60% ของยอดขาย (จ่ายจากแพลตฟอร์ม) | L1 ของเรา 3% — **แรงกว่า** ✅ |
| Shopee ExtraComm | **ร้านค้าเป็นคนออกค่าคอมพิเศษให้ผู้แนะนำเอง** (สูงสุดอีก ~60%) | = ระบบตัวแทนขาย (ข้อ 8) ของเราแบบเป๊ะ — ไอเดียผ่านการพิสูจน์แล้ว ✅ |
| Lazada Sub-affiliate | 1.68-2.64% ของยอดขาย (ชั้นสอง) | L2/L3 ของเรา 1.5%/0.75% — ปานกลาง ปลอดภัย |
| Best practice tiering (Tapfiliate/PartnerGap) | คอมหลักให้สูงก่อน ชั้นบนได้ override น้อยลงแบบ decay (เช่น 10/5/2) | 20/10/5% ของค่าธรรมเนียม = อยู่ในรูปแบบเดียวกัน ✅ |
| Industry consensus | จำกัด 2-3 ชั้น, ผูกชั้นกับ performance milestones | 3 ชั้น + ปลดล็อกตามยศภายหลัง = ตรง ✅ |

### 9.2 กันโกง (จากแนวปฏิบัติ TrafficGuard/ReferralCandy/Rewardful)
1. **Last-click attribution** — หน้าต่าง 30 วัน, คลิกล่าสุดชนะ (ป้องกันตัวแทนปล้นยอดกันเอง)
2. **กัน self-referral** — บล็อกด้วย email + device/session + ห้ามซื้อสินค้าร้านตัวเองผ่านลิงก์ตัวแทนตัวเอง
3. **Hold คอมก่อนถอน** — คอมแนะนำ/ตัวแทนอยู่ใน FINANCE_HOLD_DAYS เดียวกัน หมดหน้าต่างคืนเงินค่อยถอนได้
4. **Clawback อัตโนมัติ** — คืนเงินผู้ซื้อ = ดึงคอมทุกชั้นคืน (reversal ตามลูกโซ่)
5. **จับรูปแบบผิดปกติ** — ตัวแทนที่ refund rate สูง / ซื้อจาก IP ตัวเองซ้ำ → แอดมินเห็นใน /admin
6. **กฎโปรแกรมอัปเดตได้** — แจ้งเปลี่ยนแปลงอัตราล่วงหน้าในหน้าโปรแกรม

### 9.3 สรุปการปรับแผน
- ✅ อัตรา 20/10/5% ของค่าธรรมเนียม — คงไว้ (L1 แรงกว่าคู่แข่ง, รวมจ่ายสูงสุด 5.25% ของยอดขาย)
- ✅ ระบบตัวแทนขาย (ข้อ 8) — ยืนยันจาก ExtraComm ของ Shopee ว่าทำได้จริงในตลาดไทย
- 🔁 ปรับลำดับการเปิด: **L1 ก่อน → ทนาย+จด สคบ. → เปิด L2-L3** (ดูข้อ 5)
- ➕ เพิ่มงาน: ระบบกันโกง 6 ข้อ (ข้อ 9.2) รวมในชุดพัฒนาเดียวกัน
